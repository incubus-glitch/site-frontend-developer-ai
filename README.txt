САЙТ NIKITA — КАК УСТРОЕНО

Всё содержимое архива загружается в КОРЕНЬ сайта (nikitait.ru):

index.html            главная страница  → nikitait.ru
css/style.css
scripts/script.js     вся логика (меню, курсор, вкладки, окно просмотра, оферта, плашка)
scripts/works.js      СПИСОК РАБОТ — единственный файл, который нужно править
fonts/                шрифт Inter (лежит на сайте, к Google ничего не грузится) — общий для всех страниц
icons/favicon.svg     иконка вкладки
icons/logo-mark.svg   знак логотипа отдельным файлом (на странице он встроен в код)
offer/index.html      страница оферты (пока заглушка) → nikitait.ru/offer/

ДОБАВИТЬ РАБОТУ
  Откройте scripts/works.js, скопируйте блок { ... } и заполните:
  category, title, description, url (ссылка на сайт), image (обложка 4:5, например 'pics/works/sad.jpg').
  Пустой url = карточка «Скоро». Новая категория = новая строка в CATEGORIES.

ПЛАШКА COOKIE
  Сейчас выключена (сайт не использует cookie и аналитику).
  Если подключите Яндекс Метрику: в scripts/script.js поставьте COOKIE_BANNER_ENABLED = true
  и вставьте код счётчика. При этом понадобятся политика конфиденциальности и уведомление Роскомнадзора.

КОНТАКТЫ
  В index.html найдите «ЗАМЕНИ ССЫЛКИ НИЖЕ НА СВОИ КОНТАКТЫ» — Telegram и почта.

НОВАЯ СТРАНИЦА (например, политика)
  Папка в корне с index.html внутри: policy/index.html → nikitait.ru/policy/
  Внутри неё пути на общие файлы начинаются с ../ (../fonts/, ../icons/), ссылка на главную — href="../".
